Replicating "A Spectral Theory of Grokking"

Implementation plan, checklists and setup requirements · drafted 22 Oct 2026

Paper: A Spectral Theory of Grokking: Weight Decay induces Feature Learning. Lenz Pracher, Pascal de Jong, Oskar Lieshaus, Alan Jeffares, Steffen Rulands (LMU Munich, Cambridge). arXiv 2609.26679, cs.LG, v1 posted 22 Sep 2026.

One-line claim: after a network memorizes its training data, weight decay leaves a small leftover error. That leftover error slowly reshapes the network's features (its neural tangent kernel) until it generalizes. The theory predicts the delay scales as 1/(learning rate × weight decay).

Why this one: the core experiments use a single-hidden-layer MLP on 529 examples, so they fit this 4-CPU, no-GPU machine. The authors have not released code ("will be made publicly available upon publication"), so this is an independent rebuild from the appendix, which makes a stronger project story.

Checklist 1 · Claims we will test

  • C0 sanity: grokking cell (lr 2.36316, wd 1.18329e-4) first reaches 90% held-out at update 8,300. Done in probe: 8,300.
  • C1 four phases (Fig. 7): memorization at (0.87048, 3.293e-5); forgetting at (1.43426, 1.24846e-3) with peak train acc 0.948 ending at 0.204; no fitting at (28.6967, 1.89561e-4).
  • C2 phase map (Fig. 3a): memorize at weak decay, a grokking band, no-fit at high learning rate, failure past wd ≈ 7e-4 to 8.4e-4, instability near lr ≈ 18.9.
  • C3 boundary law: memorize/grok boundary follows lr = A / wd, paper fits A ≈ 1.09e-4 over 2e-5 ≤ wd ≤ 2e-4, empirical log-log slope −1.17.
  • C4 timing law (Fig. 3b): for grokking runs, the first update at 10% held-out accuracy scales with 1/(lr·wd).
  • C5 NTK structure (Fig. 2): mod 97, lr 40, wd 2.5e-5, 20k steps. The 97×97 label-space kernel grows Fourier "standing wave" eigenvectors after training accuracy is already 100%.
  • C6 Theorem 1: with a frozen kernel, leftover error in eigendirection j equals −2λ/(Λj+2λ) of the target. Check numerically.
  • C7 (Tier C): Transformer shows the same 1/wd boundary (A ≈ 1.69e-5) and median lr·wd·s80 ≈ 0.92.
  • C8 (Tier C): 3,000 steps of NTK alignment early on speeds generalization by ~1.5×.

Checklist 2 · Exact setup from the paper (Appendix G)

  • Task: (a + b) mod 23, all 529 ordered pairs, input = two concatenated 23-dim one-hots (46 dims).
  • Split by difference: train if (a − b) mod 23 ∈ {0,1,2,3,4,5,6,7,12,13,14,16,17,19,20,22}. Gives 368 train, 161 held-out.
  • Model: bias-free 46 → 256 → 23 ReLU MLP, He-normal init, seed 0, same init at every grid point.
  • Training: full-batch SGD, no momentum, PyTorch weight_decay (coupled L2), MSE on logits vs one-hot, 24,000 updates, eval every 100.
  • Grid: lr log-spaced 0.1 to 100, wd log-spaced 5e-6 to 2e-3.
  • Phase rules (90% threshold): grok = final train and test > 90%; memorize = train > 90%, test below; forget = train crossed 90% then ended below; else no fit.
  • Boundary: per wd column, geometric midpoint between last memorizing lr and first grokking lr; fit lr = A/wd.
  • NTK diagnostic: mod 97, 4,753 unordered pairs, 50/50 split (seed 0), 194 → 256 → 97 MLP; true-label NTK averaged by label, then diagonal-normalized.

Checklist 4 · Tests and validation

  • Split has 368/161 examples and is unchanged by shifting (a, b) → (a + r, b + r).
  • Model has no biases and 17,664 parameters (46·256 + 256·23).
  • 2-homogeneity: f(cθ) = c²·f(θ), and Euler identity Jθ = 2f, to float tolerance. This is the property the whole theory relies on.
  • Determinism: same seed gives identical curves.
  • Phase classifier unit tests on hand-made curves.
  • NTK check: kernel from torch.func matches a slow loop over samples.
  • Reference cells reproduce paper numbers (C0, C1).

Known risks

  • No official code. Small details (exact He-normal variant, eval timing) are my reading of the appendix. The 8,300 match suggests the reading is right, but we will report any cell that disagrees rather than tune it away.
  • Container resets. Long sweeps can be lost if the session idles. Mitigation: resumable runner plus regular pushes, which is why I need the repo.
  • Fit constants. The paper's boundary constants come from its 84×90 grid. A coarser grid gives noisier A and slope, so Tier A/B will be judged on shape and order of magnitude, with that stated plainly.
  • Seed 0 only. The paper sweeps one seed. I'll add a small multi-seed check on a few cells so the post doesn't overclaim.
